## 🔍 Инструкция по быстрому поиску

1. **Быстрый переход по клику:** Все ссылки в каталоге являются прямыми относительными ссылками — при клике в VS Code / Markdown Preview документ **моментально открывается в редакторе** без сбоев и ошибок кодирования.

2. **Быстрый поиск по названию или роли:** Нажмите `Ctrl + F` в редакторе/браузере и введите ключевое слово на русском языке (например, *«плагиат»*, *«диссертационный»*, *«декан»*, *«закупки»*, *«стипендии»*, *«общежития»*, *«цифровизация»*).

3. **Поиск по имени файла на латинице:** Если вы видите в папке файл вроде `dav_regulation.md` или `sop_research_output_score.md`, перейдите в [Раздел IV. Алфавитный указатель файлов на латинице](#раздел-iv-индекс-соответствия-имен-файлов-латиница--русский-язык).

4. **Поиск по структурному подразделению:** Перейдите в [Раздел I. Архитектурные пакеты по подразделениям](#раздел-i-архитектурные-пакеты-по-подразделениям-положение--ди--сопы).
