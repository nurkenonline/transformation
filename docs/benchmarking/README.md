# Аналитические и бенчмаркинговые материалы Abai University

Данная директория содержит результаты сравнительного анализа, внешних аудитов и бенчмаркинговых исследований передовых казахстанских и международных университетов в рамках трансформации НАО «КазНПУ имени Абая».

## Реестр материалов

1. [**Детальный аудит фонда ВНД Astana IT University (AITU)**](aitu_regulatory_policy_audit.md)
   - Оценка полноты фонда AITU по 10 направлениям СУР КОКСНВО (Приказ МНВО № 166 и МНЭ № 116).
   - Выявление регуляторных пробелов по линии МЗ РК (СанПиН № ҚР ДСМ-76), МЧС РК (ГО и ЧС) и диссертационных советов (Приказ МОН № 126).
   - Анализ различий организационно-правовых форм: ТОО vs НАО со 100% государственным участием.
   - Обоснование институциональных заимствований (Startup Track, MVP, High-Research Teacher, Интегральный GPA, классификатор курсов).
