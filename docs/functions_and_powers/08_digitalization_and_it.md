# Домен 08: Цифровизация, ИТ и безопасность данных (Digital Transformation & IT)

## Реестр функций домена

| Код функции | Наименование функции | Основание в НПА РК | Ответственный (Accountable) | Соисполнители (Responsible) |
| :--- | :--- | :--- | :--- | :--- |
| `FUNC-IT-ARCH-001` | Проектирование, разработка и модернизация информационных систем университета (LMS, АСУВУЗ, корпоративные порталы) | Закон РК «Об информатизации», Стратегия цифровизации ВО | Руководитель Управления цифровизации | Отдел разработки, Проректор по цифровизации / CDTO |
| `FUNC-IT-SYNC-002` | Интеграция, доработка API и автоматический обмен данными с государственными системами МНВО РК (ЕПВО / НОБД) | Приказы МНВО РК по интеграции данных, Квалтребования (№ 391) | Руководитель Управления цифровизации | Офис регистратора, Департамент HR, УИТ |
| `FUNC-IT-SEC-003` | Обеспечение информационной безопасности, аудит систем, предотвращение утечек данных и инцидент-менеджмент | Закон РК «О персональных данных и их защите», Единые требования в области ИКТ и ИБ (ПП РК № 832, п. 13) | Офицер информационной безопасности (Служба ИБ, в прямом подчинении Ректору) | Управление цифровизации, УИТ, Юридический департамент, Руководители подразделений |
| `FUNC-IT-INFRA-004` | Администрирование телекоммуникационной инфраструктуры, серверов, СХД, Wi-Fi покрытия и компьютерного парка | Квалификационные требования (№ 391) | Руководитель Управления информационных технологий (УИТ) | Служба техподдержки (Helpdesk), Системные администраторы |
| `FUNC-IT-SUR-005` | Автоматизированная выгрузка и валидация показателей Системы управления рисками (СУР КОКСНВО) по 10 направлениям через API ЕПВО | Совместный приказ МНВО № 166 и МНЭ № 116, Инструкция по таблицам СУР ЕПВО | Руководитель Управления цифровизации | Центр аккредитации и качества, ДАВ, УИТ |
| `FUNC-IT-DIPLOMA-006` | Синхронизация сервиса сквозной генерации и верификации номеров дипломов собственного образца с сервером ЕПВО | Приказ МОН РК № 39, Инструкция ИС ЕПВО по генерации номеров дипломов ОВПО | Руководитель Офиса регистратора | Управление цифровизации, Институты |
| `FUNC-IT-OSMS-007` | Регулярная выгрузка актуализированных списков студентов очной формы обучения в базу ФСМС (ОСМС) через шлюз ЕПВО | Закон РК «Об обязательном социальном медицинском страховании», Инструкция для ОСМС ЕПВО | Руководитель Офиса регистратора | Управление цифровизации, Бухгалтерия |
