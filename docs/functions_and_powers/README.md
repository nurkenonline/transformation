## Единый канонический стандарт описания доменов

Все 10 доменов Каталога оформлены по сквозному 4-блочному стандарту TFW:
1. **Раздел 1: Архитектурная модель и организационный контур** — распределение центров ответственности, разделение властей и принципы взаимодействия.
2. **Раздел 2: Реестр функций домена** — унифицированная матрица функций (Код, Наименование, Основание в НПА РК, Accountable, Responsible, Реализующий ВНД).
3. **Раздел 3: Реестр локальных нормативных актов домена** — структурированный список утвержденных Положений (REG), Должностных инструкций (JD) и регламентов (SOP).
4. **Раздел 4: Цифровой контур и функциональные модули УИС** — привязка процессов к модулям университетской информационной системы УИС SIS.
